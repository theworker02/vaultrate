# vaultrate

Vault config/rate key checks for twelve-factor services.

**Site:** https://theworker02.github.io/vaultrate/

## Install / run

```bash
git clone https://github.com/theworker02/vaultrate.git
cd vaultrate
node src/cli.js
node --test
```
